Category Code Classification
RAG + DIAL

⚖️
Risk Agent
ML + LLM Risk Scoring
Weka + DIAL
✦ Checks country jurisdiction, business type risk flags
✦ Scans Textract text for high-risk keywords (gambling, crypto, etc.)
✦ ⚡ Sequential ML-first — Weka ML runs first, DIAL only if HIGH risk or MANUAL_REVIEW
✦ ~70% of apps (LOW/MEDIUM) skip the LLM call entirely
✦ Output: riskScore, riskLevel LOW/MEDIUM/HIGH
AI Calls (conditional sequential)
POST :8080/api/risk/score
→ Weka RandomForest (no LLM tokens) — always
→ LIME explainer (feature importance)
→ EPAM AI Proxy: gpt-4o (risk report) — only if HIGH/MANUAL_REVIEW
70% apps skip DIAL  ·  Tokens: ~300–600 conditional
✅
Final Decision Engine
Orchestrator aggregates all 3 agent results. If all PASSED → APPROVED   If any MANUAL_REVIEW_REQUIRED → MANUAL REVIEW   If FAILED → REJECTED. Human reviewer can override in Review Console.

🛠️ Optimisation Roadmap
✅ Conditional DIAL calls — IMPLEMENTED ~45% saving
MCC-DIAL skips when RAG conf ≥ 0.6 (~85% apps) · Risk-DIAL skips when LOW/MEDIUM risk (~70%) · KYC-DIAL skips when score ≥ 85 (~60%). All 3 agents updated in code.
✅ GPT-4o → gpt-4o-mini for MCC — IMPLEMENTED ~15% saving
LangChain4j model switched to gpt-4o-mini in LangChainConfig.java. 87% cheaper, compact system prompt, ConcurrentHashMap result cache added.
🟡 Textract — selective AnalyzeDocument ~8% saving · pending
Use cheaper DetectDocumentText first. Only escalate to AnalyzeDocument (FORMS) if no structured KV pairs detected in the first pass.
✅ Prompt compression — IMPLEMENTED ~5–10% saving
KYC system prompt compressed to 1 line · KV context truncated to 800 chars · MCC Analyser buildContext() returns compact 1-line string (50% fewer tokens).
