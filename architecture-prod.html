Reading this diagram: Each section below represents one horizontal layer of the production stack, from the public internet edge (CDN / WAF) down through the application tier, AI agent cluster, compliance integrations, and into the data and observability planes. Arrows indicate primary data-flow direction. All internal service-to-service communication uses mTLS with mutual certificate authentication.
Layer 1 — Public Edge & CDN
🌐 Public Edge — CloudFront CDN + WAF + DDoS Shield AWS us-east-1 PoPs
☁️ AWS CloudFront
CDN + TLS Termination
Edge
  • TLS 1.3 termination at 400+ PoPs globally
  • HTTPS-only enforced — HTTP → 301 redirect
  • React SPA served from S3 origin (static assets)
  • Cache-Control headers per route (1y for hashed assets)
  • Geo-blocking for FATF high-risk jurisdictions
  • Custom domain via Route 53 with DNSSEC
🛡️ AWS WAF v2
Web Application Firewall
Security
  • OWASP Core Rule Set (SQL injection, XSS, LFI, RFI)
  • Rate-based rules: 2 000 req/5 min per IP
  • Bot control managed rule group
  • IP reputation list (Amazon Threat Intel feed)
  • Geo-match conditions on application submit endpoints
  • AWS Shield Advanced — L3/L4 DDoS protection
⚖️ AWS ALB
Application Load Balancer
:443
  • Path-based routing: /api/* → API Gateway, /* → React SPA
  • Health checks on /health every 30 s
  • Sticky sessions disabled (stateless JWT)
  • Access logs to S3 + Athena for compliance queries
  • Idle timeout: 60 s; max connections: 5 000
Layer 2 — API Gateway & Auth
🚪 API Gateway — Kong / AWS API Gateway + Cognito IdP :443 → internal :8000
🔑 JWT Auth
AWS Cognito User Pools
  • OAuth 2.0 + OIDC (access + id + refresh tokens)
  • MFA enforced for ADMIN + COMPLIANCE roles
  • Token rotation: access 15 min, refresh 24 h
  • PKCE flow for React SPA (no client secret)
⏱️ Rate Limiting
Per-merchant + Per-IP
  • 10 req / 15 min on POST /api/applications
  • 100 req / 60 s global per authenticated merchant
  • Burst allowance: 200 req/s global
  • 429 response with Retry-After header
📋 Request Validation
Schema + Sanitisation
  • OpenAPI 3.1 schema validation at gateway
  • Payload size limit: 10 MB (file uploads)
  • Content-Type enforcement
  • Input sanitisation: strip HTML/script tags
📡 API Versioning
Path & Header-based
  • /api/v1/ routes — backwards-compatible
  • Deprecation header on v0 endpoints (→ sunset date)
  • Canary routing: 5% to v2 during rollout
  • CORS policy: allowed origins from env config

Port: 3001 (internal)
🎼Orchestrator Service Stateless
  • Publishes 3 parallel events to RabbitMQ cluster
  • aggregateResults() with timeout & retry
  • Maker-checker: Reviewer → Senior Approver workflow
  • 4-eyes enforcement at API level (segregation of duties)
  • Dead Letter Queue → ops alert channel
  • Circuit breaker: Resilience4j pattern (50% fail → open)
  • Outbox pattern for guaranteed event delivery
🏷️MCC Analyser Spring Boot 3.5 · Java 21 LTS
  • LangChain4j RAG pipeline — MCC Handbook PDF → text-embedding-3-small
  • ChromaDB vector store (in-cluster) → semantic similarity search
  • GPT-4o via EPAM AI Proxy (conditional — conf < 0.6 only)
  • 2–3 replicas; @Lazy beans — safe cold start
  • mTLS from Orchestrator (mutual cert auth)
  • Returns: mccCode, confidence, reasoning, detectedRisks[]
Port: 8091 (internal Kubernetes service)
⚖️Smart Risk Scoring Spring Boot 3.5 · Weka ML + LIME
  • Weka RandomForest model (risk_model.ser) — 10 features, always runs first
  • LIME Explainer — human-readable feature importance for regulatory rejection letters
  • GPT-4o LLM Risk Report only if riskLevel = HIGH or MANUAL_REVIEW (~30%)
  • Risk model versioned in S3; hot-reload without pod restart
  • Open Banking transaction history feed boosts model accuracy
  • Returns: riskScore 0–100, riskLevel, riskFactors[], LIME explanation
Port: 8080 (internal Kubernetes service)

Layer 5 — AI Services & Compliance Integrations
🤖 AI / LLM Services Conditional calls · ~68% cost saving
🧠 EPAM DIAL · GPT-4o
ai-proxy.lab.epam.com
Conditional
KYC Agent: called only when score < 85 (~40% of apps). Risk Agent: only HIGH/MANUAL_REVIEW (~30%). Compressed prompts ≤ 800 chars. Token budget enforced at gateway. Fallback: structured rule result if DIAL times out (>5 s).
☁️ AWS Textract
eu-west-1 · Async API
Async
StartDocumentAnalysis + SNS callback (replaces blocking sync call). PDF → Ghostscript 200 DPI PNG per page. S3 pre-signed URL passed to Textract (no upload to Textract directly). Results stored encrypted in S3.
🗂️ ChromaDB Vector Store
MCC Handbook embeddings
RAG
In-cluster ChromaDB pod with MCC Handbook PDF pre-embedded via text-embedding-3-small. Top-k=5 similarity retrieval. Embedding index versioned and refreshable without service restart.
🛡️ KYC / AML / Compliance Integrations All calls server-side · keys in Vault
👁️ Onfido / Sumsub
Biometric Identity Verification
Critical
Government ID OCR + biometric liveness check. NFC chip read where available. eIDAS / RBI KYC / FinCEN compliant. Returns identity confidence score and fraud flags. Called during Step 1 of onboarding before any form data is accepted.
🔍 ComplyAdvantage
AML · Sanctions · PEP Screening
Critical
Real-time screening: OFAC SDN, UN, EU, HM Treasury. PEP database + adverse media. Webhook-based ongoing monitoring — re-screens existing merchants when new sanctions published. Auto-triggers SAR filing on match.
🃏 Mastercard MATCH List
Terminated Merchant DB
Critical
Checks if merchant or principals were previously terminated by any acquirer for fraud or excessive chargebacks. Mandatory before card scheme acceptance. Failure to check = acquiring bank liability.
🏛️ Bureau van Dijk Orbis
Company Registry · UBO Lookup
High
Verify company exists, registered address, incorporation date, status. UBO (Ultimate Beneficial Owner) ownership chain. 400M+ company records. Alternatives: Companies House (UK), MCA (India), OpenCorporates.
🏦 Banking & Financial Verification Open Banking · OAuth 2.0
🔗 Plaid / TrueLayer
Open Banking — Bank Account Verification
High
Verify merchant bank account ownership via Open Banking consent flow. Pull 3–6 month transaction history for financial health assessment. Average balance and revenue trends feed into the Risk Agent ML model. Plaid covers US/CA; TrueLayer covers EU/UK.
💳 SWIFT BIC / IBAN Validation
Accuity · SWIFT Ref API
High
Validate merchant bank details (BIC, IBAN, sort code) before onboarding completes. Prevents misdirected payouts. SWIFT Ref returns bank name, country, branch, and validity. Accuity cross-checks OFAC status of receiving bank.
📧 Twilio Verify + SendGrid
Email & SMS OTP
High
OTP verification on email and phone during onboarding (currently no verification). Application status notifications: received, processing, approved/rejected. Document expiry warnings 30/60/90 days before lapse.
📡 Notifications & Webhook Delivery Async · Signed · Retried
🔔 Svix Webhooks
Signed Event Delivery to Partners
Medium
HMAC-signed webhook events on application status changes. Retry logic with exponential backoff. Delivery logs and merchant self-service portal to manage subscriptions and replay failed events.
🔐 Signicat / DocuSign
eSignature on Merchant Agreement
Medium
Legally binding digital signature on merchant T&Cs and service agreement. eIDAS-qualified signatures for EU. Timestamped and tamper-evident. Replaces the current manual signing step in the onboarding flow.
📊 VIES / GSTIN / EIN
Tax Registration Validation
Medium
Verify tax registration numbers are real and currently active. EU: EC VIES API (free). India: GSTN API. US: IRS EIN validation. Prevents shell company onboarding with fabricated tax IDs.

Primary application database
3-node replica

Caching · Session · Rate-limit counters
ElastiCache
  • AWS ElastiCache for Redis — cluster mode
  • Replaces in-process Map<id, app> (lost on restart)
  • Rate-limit counters per merchant ID
  • Application processing state cache (TTL: 30 min)
  • Session token revocation list
  • Auth nonce store for PKCE flow
🗂️ AWS S3
Document storage · Static assets
SSE-KMS
  • Uploaded documents: SSE-KMS encrypted, versioned
  • Access via pre-signed URLs only (no public read)
  • Bucket policy: deny non-TLS requests
  • Object Lock (WORM) for compliance documents
  • S3 Access Logs → Athena for audit queries
  • Lifecycle: move to Glacier after 90 days
🔐 HashiCorp Vault
Secrets management · PKI
Zero .env files
  • All API keys, DB credentials, certs in Vault
  • Dynamic secrets: MongoDB credentials rotated hourly
  • PKI engine: mTLS certificates for all services
  • Kubernetes Auth method — pod identity (no static keys)
  • AWS KMS as Vault auto-unseal backend
  • Audit log: every secret access logged
Layer 7 — Observability, CI/CD & Compliance Reporting
📡 OpenTelemetry + Grafana Stack Distributed tracing
🔭 OpenTelemetry Collector
Traces · Metrics · Logs
Auto-instrumentation on Node.js (via @opentelemetry/auto-instrumentations-node) and Spring Boot (via Micrometer). Trace IDs propagated across React → Node → RabbitMQ → Java services. W3C TraceContext headers on all requests.
📊 Grafana + Loki + Tempo
Dashboards · Log search · Trace viewer
Pre-built dashboards: application throughput, agent latency P50/P95/P99, queue depth, AI call rate, error rate per service. Loki for log aggregation (PII masked). Tempo for distributed trace visualisation. Alertmanager → PagerDuty on SLA breach.
🚨 PagerDuty Alerting
On-call escalation
Alerts: DLQ depth > 0, agent silent for > 60 s, Textract error rate > 5%, MongoDB replica lag > 10 s, SLA timer breach on MANUAL_REVIEW applications (> 48 h without decision).

What Stays Unchanged in Production
The AI pipeline architecture is production-quality as built: conditional LLM calls (KYC < 85, Risk HIGH only), RAG classification via LangChain4j, Weka ML + LIME explainability, AWS Textract OCR, and the ~68% AI cost savings are genuine design wins that require minimal change. The core agent logic (KYC cross-validation, MCC RAG, Risk ML) is sound. The biggest gaps — now addressed in this production diagram — are in compliance integrations, secure secret and document management, HA data services, mTLS between services, and operational infrastructure.
